# Chup Desktop Widget: releases

Installers and update files for the Chup Desktop Widget. This repository holds
no source code; releases are published here by the build pipeline.

**Install:** download `chup-widget-setup.exe` from the
[latest release](https://github.com/saadramay/chup-desktop-widget-releases/releases/latest)
and run it. Installed widgets update themselves from here.
